This module bridges *Sale Readonly* and *Project Readonly*: it grants
users holding the project read-only group access to the *Projects*
smart button and to the *Project* field of sales orders.

Without this module, those elements (added by the `sale_project`
standard module) are reserved for project users, so read-only sales
users cannot browse the projects and tasks of a sales order from its
form view.

The module is auto-installed when *Sale Readonly*, *Project Readonly*
and *Sale Project* are installed.
